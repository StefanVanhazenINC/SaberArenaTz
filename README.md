# Saber Arena
Тестовое задание в котором надо продемонстрировать навыки проектирование архитектуры проекта и реализацию механик по ТЗ. Была сделана боевая арена, где игрок по триггеру начинает бой. Арена завершается поссле смерти игрока или когда все враги побеждены. 

Были реализованы системы для арены, управления персонажей, система оружия, противники, подсчет статистики и переход между состояниями игры.

## Технологии 
- Unity 6 (`6000.3.9f1`)
- Universal Render Pipeline
- Zenject - Dependency Injection и управление временем жизни сервисов
- UniTask - асинхронная загрузка и игровая логика
- New Input System
- ScriptableObject — игровые конфигурации
- Alchemy - для удобной работы с редактором 

- ## Архитектура
Проект использует смешанную архитектуру, сочетающую data-driven подход,
сервисный слой, Dependency Injection и компонентную сборку игровых сущностей.

Данные и параметры сущностей вынесены в конфигурации `ScriptableObject`.
Общая игровая логика представлена сервисами, доступ к которым осуществляется
через интерфейсы. Zenject используется для регистрации зависимостей, управления
их временем жизни.

Инсталлеры выступают точками композиции разных уровней:

- `ProjectContext` регистрирует глобальные сервисы приложения;
- `SceneContext` регистрирует сервисы игрового сеанса;
- `CharacterInstaller` собирает зависимости отдельного персонажа.

- Система оружия была разработана, чтоб быть максимально гибкой. Конкретное оружие собирается из
реализаций `IShooter`, `IReloading`, `IAltWeaponUse` и дополнительных
`IWeaponDataModule`, указанных в `WeaponConfig`.

Из этих модулей дизайнер может создавать новые варианты оружия, комбинируя и
настраивая готовые модули через Inspector.Если требуется новая механика,
программист реализует соответствующий интерфейс, после чего модуль можно
повторно использовать в разных конфигурациях.
